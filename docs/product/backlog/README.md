# 产品待办

## 状态

- 版本：v0.1
- 最近更新：2026-08-22
- 用途：保存已识别但**不自动执行**的范围、结构和发布计划。

## 使用规则

1. 每个独立议题创建一个文件，文件名使用 `YYYY-MM-DD-short-topic.md`。
2. 新议题状态必须是 `待手动激活`。
3. Goal Agent 不得自动执行任何待办。
4. 只有维护者显式把条目移入 `docs/product/progress-tracker.md` 的当前优先级队列后，才能开工。
5. 激活时必须在原待办记录激活日期、执行会话和最终结果。
