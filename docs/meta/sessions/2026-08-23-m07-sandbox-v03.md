## 决策

1. 核心不变量定为默认拒绝、policy/enforcement 分离、根是身份不是字符串、exact argv 进 jail、不可用即拒绝、protected state 优先。
2. 区分 runner failure 与 sandbox denial，并要求 exit gate + fatal signature + informational exclusion。
3. 用 flowchart 表达 policy→identity→backend→diagnosis，用 state diagram 表达 FailClosed/Partial/DeniedEffect。
4. 新增反例覆盖 symlink 身份漂移、后端缺失静默放行、shell string 重解析、denial 误判业务错误、partial 当 full、env 泄露、session temp 泄漏和 broad home 覆盖 agent state。
5. 完整因果链采用 Linux npm install：roots 身份过滤、bwrap argv、denial 分类、unavailable fail closed、显式 off 审计和 temp 清理。

## Polish

1. 统一 policy、enforcement、canonical identity、stable roots、runner failure、denial dialect、partial enforcement 术语。
2. 通风柜类比只承担入门，随后给出 Spec、身份管理和失败分类机制。
3. 设计取舍表补充应用层检查到 remote executor 的层级选择。
4. 明确 Pi 核心是集成点而非内置强制层，避免把宿主能力误写成框架事实。
