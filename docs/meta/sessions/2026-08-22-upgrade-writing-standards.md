# 会话：升级 Polish 写作标准与密度检查

## 元数据

- 日期：2026-08-22
- 状态：已完成
- 目标：修复 Goal Agent 产出的两个质量问题：翻译腔和信息密度过高。

## 范围

### 范围内

1. 在 Polish Agent 验收标准中加入中文写作六条规则。
2. 在 Implementation Review Agent 任务和验收标准中加入信息密度检查。

### 范围外

- 修改已有的 C-01 或 C-02 正文。
- 创建科技写作 Skill（后续独立任务）。

## 工作记录

### Polish Agent 新增中文写作六条规则

1. 短句：一句话一个意思，超 30 字含逗号考虑拆分。
2. 主动语态。
3. 具体名词代替抽象名词。
4. 避免翻译腔（附正反例）。
5. 术语首次出现给英文，后续统一用中文名。
6. 类比贴近日常经验，不用工程隐喻解释工程概念。

### Implementation Review Agent 新增密度检查

任务新增第 7、8 条：
7. 初学者路线超 80 行建议拆分或标记进阶。
8. 理论和三家框架源码不同时塞同一节。

验收标准新增两条对应检查。

## 结果

Goal Agent 恢复后，后续每一节的 Polish 和 Implementation Review 都会执行新标准。已有的 C-01 和 C-02 草稿可以在 Goal Agent 恢复后按新标准重写润色。
