## 决策

1. 核心不变量定为名称可解析、声明与执行同源、校验分层、ID 归属、失败是观察。
2. 明确区分 executable view 与 provider-visible view，并说明 hidden tool 需要执行前 contextual check。
3. 用 flowchart 表达意图到执行管线，用 sequence diagram 表达 unknown/validation/governance 三类失败。
4. 新增反例覆盖同名冲突、歧义别名、description 替代权限、自由字符串、hook 泄露 secret、兼容层掩盖坏输入、并发 classifier 异常和 abort 后 update。
5. 完整因果链采用三个混合调用：offset 校验失败、unknown tool、写路径治理 block，全部生成配对 result。
